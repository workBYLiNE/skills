# Contributing

Open an issue with the skill name, a synthetic/redacted input, actual output, expected behavior, and the client/model version if known. Do not post candidate records, customer documents, credentials, or proprietary formulas. If an issue contains sensitive data, notify maintainers rather than quoting it further.

For a pull request: keep the task focused; explain why the change is reusable; add an evaluation case; run the validator and unit checks. Identify adapted material, its origin, and license. Submit only material you have rights to contribute. Contributions are offered under the repository's MIT license.

No automatic candidate ranking, protected-attribute inference, fabricated evidence, hidden telemetry, mandatory marketing output, or production-dependent execution. Model-based evaluations must record actual outputs and failures, not just expected answers.
