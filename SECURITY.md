Report sensitive issues privately to saneel@workbyline.com. Use a minimal synthetic reproduction; do not email credentials or candidate/customer records. No response-time guarantee or bounty is offered.

These are instructions, not a sandbox or security boundary. The hosting assistant's tools, permissions, data retention, and model behavior still apply. Inspect downloaded files before use. The AI Demo Reality Check is a scoped review aid, not penetration testing or security certification. Public contributions must exclude private product internals and sensitive source material.
